# «Ваше название» — сайт компьютерного клуба (Laravel)

## 1. Новый проект (нужны PHP 8.2+ и Composer)

    composer create-project laravel/laravel club
    cd club

## 2. Скопируйте файлы из архива поверх проекта
Папки app, config, database, public, resources, routes — с заменой.
(Лучше делать в НОВОЙ папке, чтобы не смешивать со старым проектом.)

## 3. Создайте базу и запустите

    php artisan migrate:fresh --seed
    php artisan serve

Откройте http://127.0.0.1:8000
Демо-вход в кабинет: +7 (999) 000-00-00, пароль demo12345.

## 4. Название и контент
- Название клуба: в файле .env добавьте строку  CLUB_NAME="Моё название"
  (по умолчанию «Ваше название»).
- Все тексты, цены, залы, акции, FAQ, адреса и телефоны — в одном файле config/club.php.
- Цены и характеристики в файле — условные примеры, замените на свои.
- Новые клубы добавляйте в 'locations' — они появятся в контактах и в форме брони.

## 5. Заявки на бронь
Форма /book сохраняет заявки в базу. Посмотреть:

    php artisan club:bookings

## 6. Личный кабинет и баллы
- Значок человека в шапке → вход по телефону (аккаунт есть → пароль, нет → регистрация).
- Оплаты записывает администратор командой:

      php artisan club:payment +79991234567 480 --club="Клуб на главной" --spend=100 --item="VIP — 3 часа:480:1"

- Правила: 1 балл = 1 рубль, списать до 30% суммы (config/bonus.php).
- Сколько баллов начислять — .env: BONUS_EARN_PERCENT=5 (условно, поставьте своё).

## Перед запуском для клиентов
1. Подтверждение номера по SMS (иначе можно зарегистрироваться на чужой номер).
2. Юрист: политика персональных данных, правила клуба и бонусной программы.
3. HTTPS на домене.
4. Установка как приложения (PWA) работает по HTTPS.
