# smoke Line — приложения для смартфонов

## Вариант 1. PWA (уже встроено, ничего собирать не нужно)
Сайт умеет устанавливаться как приложение, работать в полноэкранном режиме
и показывать страницу «Нет соединения» без интернета.

Требования: сайт должен открываться по HTTPS на вашем домене
(для проверки на своём компьютере достаточно http://localhost:8000).

- Android (Chrome): откройте сайт → кнопка «Установить приложение» внизу страницы
  или меню ⋮ → «Установить приложение».
- iPhone (Safari): «Поделиться» → «На экран “Домой”».

## Вариант 2. Файлы Android (.apk/.aab) и iOS через Capacitor
Папка `mobile/` — оболочка приложения, которая открывает ваш опубликованный сайт.

1. Опубликуйте Laravel-сайт на хостинге с HTTPS.
2. В `mobile/capacitor.config.json` замените `https://ВАШ-ДОМЕН.ru` на адрес сайта.
3. Установите Node.js, затем:

       cd mobile
       npm install
       npx cap add android
       npx cap sync
       npx cap open android      # откроется Android Studio → Build → Generate Signed Bundle / APK

4. Для iOS нужен Mac с Xcode: `npx cap add ios`, `npx cap open ios`.

## Важно про магазины приложений
Google Play и Apple App Store ограничивают приложения, связанные с табаком и
вейпами, а Apple также отклоняет «обёртки» над сайтом без собственной
функциональности. Перед публикацией прочитайте правила магазинов; самый
надёжный способ распространения без магазинов — PWA или установка .apk напрямую.
